Stream Tester

Auto mode: fetches GET /api/stream/{busId} itself, then keeps every channel alive by re-fetching a fresh directUrl on a timer (before the vendor's short-lived token expires) and on player error — a paste-once static page can't do either, so this is the closer-to-production path. "Stop All" also calls POST /api/bridge/stop per channel so the backend's capacity slot (see chemitoapi.maxActiveChannels) frees immediately instead of waiting out its TTL.
Manual mode: paste the RAW response body of GET /api/stream/{busId} below — either the unparsed JSON text (with literal & etc., exactly as the server sent it) or already-parsed JSON. No auto-refresh; re-paste to reconnect a dead URL.
